Student Management System

A professional console-based Student Management System built using C++ with CRUD operations, modular programming, and file handling support.

View GitHub Download EXE

Project Features

Add Student

Add student records including full name, roll number, and marks.

Display Students

Display all saved student records in a clean formatted structure.

Search Student

Search student records quickly using roll numbers.

Update Student

Modify student details and update marks easily.

Delete Student

Remove student records safely from the system.

File Handling

Student data is stored permanently using file handling in C++.
